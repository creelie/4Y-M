# Exact finite response checks

Run python check-response.py. The check uses only the standard library and writes response-checks.json. It checks 64 finite identities of the response sections of release v4.42.0, which the current manuscript no longer contains; that material is in the Hexagon preprint 2610.00341v7 and in the v4.42.0 archive. It does not prove (D), (E) or a continuum mass gap.
